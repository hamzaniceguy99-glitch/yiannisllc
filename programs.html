Program 01 · Worth it past a point

Screen printing

Screen printing has a setup cost per colour, so it gets cheaper per shirt as quantity rises and makes no sense for a dozen. We will tell you where your order sits and point you to transfer printing when that is genuinely the better value.

Program 02 · Digitised once, kept on file

Embroidery

Embroidery needs artwork converted into a stitch file, which is a one-off cost we keep on file so reorders are cheaper. Fine detail and small text do not survive stitching, and we will show you what will actually be legible before you commit to it.

  • Businesses

Program 03 · For small numbers

Heat transfer & digital

Right for a dozen shirts, for individual player names, or for full-colour artwork that would need too many screens. Cheaper to set up and less durable over many washes than screen printing, and we would rather say so than let you discover it.

Team & workwear programmes

Businesses that reorder uniforms every few months should not re-approve artwork each time. We keep the files, thread colours and size breakdown, so a reorder is a phone call — and the twelfth shirt matches the first, which is the point of a uniform.
